# Contributing

## Proposing a change

1. Start from a work item: What, Done when, a spec or context reference, Out of scope.
2. Work on a branch; keep one work item per pull request.
3. Open the pull request with the repository's template and answer every section.

## Local setup

Run `scripts/setup`. It stands the environment up and ends in verify.

## Before you open a pull request

Run the verify command listed in [AGENTS.md](AGENTS.md) §2 and put the command and its result in the
pull request's "How verified" section. List any check you could not run.

## Review and merge

A human merges every pull request. An agent never merges its own.
